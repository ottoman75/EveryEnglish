# EveryEnglish — 매일 30분 영어회화

**바로 쓰기:** https://ottoman75.github.io/EveryEnglish/ — 폰에서 열고 공유 → '홈 화면에 추가'

상황별 15분 회화 챕터로 **직접 말하고**, 틀린 문장은 **맞힐 때까지 다시** 만나는 모바일 웹앱.

## 실행

```bash
npm start            # 또는: python3 -m http.server 5173
```
→ 브라우저에서 `http://localhost:5173`

- 휴대폰에서 쓰려면 같은 Wi‑Fi에서 `http://<내 PC IP>:5173` — 단, 음성 인식은 https 또는 localhost에서만 동작한다. 휴대폰에서 마이크까지 쓰려면 GitHub Pages 같은 https 호스팅에 올린다(정적 파일이라 그대로 올리면 된다).
- `index.html`을 더블클릭해서 열어도 동작한다(이 경우 키보드 입력만).
- 홈 화면에 추가하면 앱처럼 전체 화면으로 열린다.

## 원어민 음성

모든 문장(약 2,500개)은 오픈소스 뉴럴 TTS **Kokoro-82M**(Apache-2.0)으로 미리 녹음해 `audio/`에 들어 있다. 기기와 상관없이 같은 미국 원어민 음성으로 재생되고, 대화 상대는 인물마다 다른 목소리를 쓴다. 문장을 추가했다면:

```bash
npm run audio:setup   # 최초 1회 (약 350MB 모델을 ~/.cache에 내려받음)
npm run audio         # 바뀐 문장만 새로 녹음
```

`내 정보 → 목소리`에서 기기 음성으로 바꿀 수도 있다.
